Phase 2: Execution Roadmap (Interactive)

Select items below to simulate size reduction on the projected dashboard. Click rows to view technical implementation details.
1. Strip x86 / x86_64 Native Libs
-3.69 MB
Context: lib/x86/ is 1.89 MB and lib/x86_64/ is 1.80 MB. These are emulator-only architectures and are dead weight for direct-distributed alpha/dev APKs.

Action: Add ndk { abiFilters "armeabi-v7a", "arm64-v8a" } to the buildTypes or productFlavors used for direct distribution.
Note: Play Store users already avoid this via AAB ABI splits.
2. Audit & Remove kotlin-reflect
-2.00 MB (Est.)
Context: 2,330 kotlin/reflect/jvm/internal references exist untouched in the new dex. This is a massive legacy dependency likely pulled in via Dagger or Gson fallback paths.

Action: Run ./gradlew :app:dependencies --configuration indiatodayProdReleaseRuntimeClasspath | grep -i reflect to find the pull-in point. Resolve the transitive dependency before removal to prevent runtime crashes.
3. Convert PNG/JPEG to WebP
-350 KB (Est.)
Context: Legacy drawables in res/ are uncompressed.

Action: In Android Studio, right-click res/ → Convert to WebP. Use lossless for UI icons and lossy (75%) for photographic assets. Run a subsequent unused-resources lint pass to catch orphaned XML drawables.
4. Migrate Shared Gson Models to Kotlinx.serialization
-350 KB (Est.)
Context: Models like ElectionWidgetParentBase, StateLists, and PartyLabels are shared across 17 screens and still rely on Gson.

Action: Long-term tech debt task. Convert model-by-model to @Serializable. Once complete, completely remove the Gson dependency and its associated ProGuard rules to allow R8 to strip the remaining parser code.
