Phase 2 & 3: Active & New Architectural Opportunities

Toggle checkboxes to simulate size impacts on the primary build target. Click rows to inspect implementation steps.
1. Drop x86 / x86_64 Native Libs for Direct Distribution Low Risk -3.69 MB
Analysis: lib/x86/ is 1.89 MB and lib/x86_64/ is 1.80 MB. These emulator binaries only bloat direct/alpha builds.
Execution: Add ndk { abiFilters "armeabi-v7a", "arm64-v8a" } to the distribution build variant in app/build.gradle.
2. Isolate and Strip kotlin-reflect High Impact -2.00 MB
Analysis: 2,330 kotlin/reflect/jvm/internal references remain in DEX. It is one of the heaviest jars in the Android ecosystem.
Execution: Audit classpath using ./gradlew :app:dependencies --configuration indiatodayProdReleaseRuntimeClasspath | grep -i reflect and eliminate transitive injection.
3. Enable R8 Full Mode (Code Outlining & Class Merging) New Finding -850 KB
Analysis: Default R8 runs in compatibility mode. Full Mode enables aggressive dead-code elimination, unboxing, class merging, and method outlining.
Execution: Add android.enableR8.fullMode=true in gradle.properties and verify reflection-reliant entry points.
4. Font Deduplication & Glyph Subsetting (pyftsubset) New Finding -450 KB
Analysis: font_medium.ttf and InterTightBlack.ttf are duplicated across assets/ and res/font/, carrying unused extended character glyphs.
Execution: Deduplicate storage and run pyftsubset to strip unused non-Latin/extended ligatures or transition to Google Play Downloadable Fonts.
5. Convert Raw PNG/JPEG Drawables to Lossless/Lossy WebP Asset Compression -350 KB
Analysis: Raw drawables consume uncompressed size in res/.
Execution: Right-click res/drawable* → Convert to WebP (Lossless for icons, 75-80% quality for imagery). Follow with an unused-resources lint pass.
6. Audit Java 8+ Desugaring Configuration (desugar_jdk_libs) New Finding -250 KB
Analysis: Using the full desugar library adds large companion methods in DEX.
Execution: Switch from desugar_jdk_libs (Full) to desugar_jdk_libs_minimal if only using basic java.time or Streams.
7. Complete Gson → kotlinx.serialization Transition Tech Debt -300 KB
Analysis: Shared models across screens (ElectionWidgetParentBase, StateLists) hold Gson in the runtime classpath.
Execution: Migrate shared models to @Serializable and remove the Gson dependency and its associated keep-rules entirely.
